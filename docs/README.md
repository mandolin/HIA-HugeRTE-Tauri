# Documentation

This directory contains public documentation for users and contributors.

Current documents:

- [Application boundary](application-boundary.md): first-release scope, platform target and safety boundary.
- [Portable user guide](../packaging/portable/README.md): extraction, WebView2, open and save instructions (Chinese).

`v0.1.0` is the completed P1 portable release baseline. It is intentionally a manual-association portable application: Windows **Open with** may point to the extracted executable, but the application does not silently register or take over file associations.
