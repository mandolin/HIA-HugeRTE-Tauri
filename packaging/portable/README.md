# HIA HugeRTE 便携版使用说明

## 启动

解压整个压缩包到任意可写目录后，双击 `HIA HugeRTE.exe` 启动。不要只复制其中的单个文件。

本版本使用系统 Microsoft Edge WebView2 Runtime。Windows 10/11 的常规环境通常已具备该运行时；若无法启动，请由设备管理员安装或修复 WebView2 Runtime 后再试。

## 打开 HTML 文件

- 在应用中使用“打开”；
- 将 `.htm` 或 `.html` 文件拖入应用窗口（可一次拖入多个，各自在新标签页打开）；
- 在资源管理器中右键目标文件，选择“打开方式”→“选择其他应用”→“在这台电脑上查找其他应用”，再选择解压目录中的 `HIA HugeRTE.exe`。

选择后 Windows 会把目标文件路径传给本应用。便携版不会自动修改系统文件关联或注册表；是否将本应用保留为默认打开方式，由当前 Windows 用户在系统界面中决定。

## 多标签页

- 每个打开的文件占一个标签页；点击标签切换，`✕` 关闭（有未保存修改时会先弹出确认）。
- 标签页较多时收纳进右侧“更多标签”菜单；单个窗口最多 20 个标签页。

## 资源管理侧栏

- 打开文档后，左侧显示该文档所在目录的**只读**目录树（右上按钮可显示/隐藏）。
- 顶部地址栏与 Windows 资源管理器一致：每个路径段可点击跳转，小箭头展开同级文件夹，`↑` 回上一级；地址栏过长时可用鼠标滚轮横向滚动。
- 侧栏右缘可拖拽调宽（选中后也可用左右方向键微调），宽度会被记住。
- 图片/样式表等资源支持预览与“插入相对引用”；目录树只做浏览，不会修改文件。

## 历史记录

- “历史 ▾”列出最近打开的文件（最多 50 条），点击即可重新打开；文件已被移动或删除时，打开会提示失败（列表内灰显标注为后续版本加固项）。
- 可开启“不记录模式”，也可清空历史（需确认）。
- 记录保存在程序目录的 `data/recent-files.json`（目录不可写时自动退回用户数据目录）；全程不写注册表。

## 设置（打开方式与版本）

- 头部「设置 ▾」中可把本应用**注册到 Windows「打开方式」列表**（每用户、随时可移除；不会设为默认程序，也不修改系统默认应用）。
- 同处提供「打开 Windows 默认应用设置」按钮，由你在系统界面自行选定默认程序。
- 版本区显示当前版本并提供「打开下载页」。本程序**不联网检查更新、不会自动下载或替换自身**；有新版本时请到下载页手动替换（保留你的 `data/` 目录即可保住历史记录）。

## 保存

“保存”会写回本次打开的文件；“另存为”会创建新文件。本版本只支持 UTF-8 编码的 `.htm` 与 `.html` 文本文件。
