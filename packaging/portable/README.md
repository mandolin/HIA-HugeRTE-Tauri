# HIA HugeRTE 便携版使用说明

## 启动

解压整个压缩包到任意可写目录后，双击 `HIA HugeRTE.exe` 启动。不要只复制其中的单个文件。

本版本使用系统 Microsoft Edge WebView2 Runtime。Windows 10/11 的常规环境通常已具备该运行时；若无法启动，请由设备管理员安装或修复 WebView2 Runtime 后再试。

## 打开 HTML 文件

- 在应用中使用“打开”；
- 将 `.htm` 或 `.html` 文件拖入应用窗口；
- 在资源管理器中右键目标文件，选择“打开方式”→“选择其他应用”→“在这台电脑上查找其他应用”，再选择解压目录中的 `HIA HugeRTE.exe`。

选择后 Windows 会把目标文件路径传给本应用。便携版不会自动修改系统文件关联或注册表；是否将本应用保留为默认打开方式，由当前 Windows 用户在系统界面中决定。

## 保存

“保存”会写回本次打开的文件；“另存为”会创建新文件。初版只支持 UTF-8 编码的 `.htm` 与 `.html` 文本文件。
